## Goal

`POST /api/tickets` turns a transcript into a ticket through `ITicketGenerator`, with the deterministic fake generator selected by configuration.

- `src/VoiceToTicket.Api/Features/Tickets/GenerateTicketEndpoint.cs`

## Out of scope

- Transcription, web, Docker.

## Acceptance criteria

- [ ] Request `{ transcript }` validated with built-in Minimal API validation (`AddValidation()` + DataAnnotations): 20–20,000 characters. Violations return 400 ProblemDetails with `code: "validation"`.
- [ ] Response `{ ticket, provider, model, durationMs, usage }` as in plan 4.4; `provider` is `"Fake"`, `model` is `"fake"`, `usage` is `null`; `durationMs` is measured with the injected `TimeProvider`.
- [ ] `FakeTicketGenerator` behaves as in plan 4.6, is deterministic, and every ticket it returns passes `TicketValidator` (tests for a bug-like and a feature-like transcript).
- [ ] `TicketGenerator:Provider` is bound with `IOptions<T>` + `ValidateOnStart`; an unknown value makes startup fail with a clear message (test).
- [ ] Integration tests: 200 for a Bug transcript, 200 for a Feature transcript, 400 too short, 400 too long, 400 missing body.
- [ ] The transcript text is not logged at Information level or above.
- [ ] `dotnet build` 0 warnings; `dotnet test` passes.
