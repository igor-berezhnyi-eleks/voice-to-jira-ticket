# T1.4 — Web scaffold and both pages (read-only ticket)

- **Milestone:** M1 Walking skeleton
- **Status:** todo
- **Depends on:** T1.3
- **Plan sections:** 3 (D3, D8, D9), 4.2 (`web/`), 4.8 (structure only), 4.9 (development)
- **Parallel-safe with:** T2.1

## Goal

A React + Vite + TypeScript app where the user pastes or types a transcript on Page 1, presses Generate, and sees the ticket's fields (read-only) on Page 2, using generated TypeScript types for the contract.

## Files

- `web/**` (except `web/src/contract.ts`, which is only written by `npm run gen:contract`)

## Out of scope

- Recording (T2.3), editing fields, preview, copy, JSON download (M4). Styling beyond plain readable CSS. Router, state library, UI kit (D3).

## Acceptance criteria

- [ ] Vite + React + TypeScript (`strict`), with `npm` scripts: `dev`, `build`, `test` (Vitest, single run), `lint` (ESLint), `gen:contract` (json-schema-to-typescript from `../contract/ticket.schema.json` to `src/contract.ts`).
- [ ] Vite dev server proxies `/api` and `/health` to the API (`http://localhost:5xxx` from launchSettings; document the port in the log).
- [ ] `src/api.ts`: `generateTicket(transcript, signal)` returns the typed response or throws a typed error carrying ProblemDetails `code`; unit-tested with a mocked `fetch` (success, 400 validation, network failure).
- [ ] Page 1: textarea, Generate button disabled under 20 characters or while a request runs, error message on failure, transcript kept on error.
- [ ] Page 2: type badge and all fields of the ticket's type shown read-only; `"Not provided"` values visible as such; missing-information list; Back button returns to Page 1 with the transcript intact.
- [ ] Banner "Fake generator active — tickets are not real" when `provider === "Fake"`.
- [ ] `npm run build`, `npm test` and `npm run lint` pass; `node scripts/check.mjs` passes.

## Verification

```
cd web && npm ci && npm run gen:contract && npm run build && npm test && npm run lint
node scripts/check.mjs --all
```

Agent check: run the API and `npm run dev`, open the page in the browser pane, paste a transcript, confirm Page 2 shows the fake ticket. Note the result in the log.

Manual check for the human: the same, in your own browser.
