## Goal

One Playwright test (Chromium) drives the whole UI against the real API running with `Provider=Fake`: paste transcript → Generate → Page 2 → edit a field → preview updates → Copy → Back keeps the transcript. `npm run e2e` runs it locally and passes. After it, the human runs the "Full demo flow works" gate by voice.
