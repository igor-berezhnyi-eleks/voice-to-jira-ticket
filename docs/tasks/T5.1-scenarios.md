## Acceptance criteria

- [ ] Exactly the 10 IDs from plan 7.1, each valid JSON in the 7.1 schema.
- [ ] Scripts are natural speech, English only, one invented product domain (Ledgerly).
- [ ] Every fact appears in or follows directly from the script; every trap text does NOT appear in the script.
- [ ] `expectedMissing` uses contract field paths (`bug.environment`, ...) or `general` for field-null gaps.
- [ ] Two scenarios are bug with detail extremes, one feature has explicit acceptance criteria, one is vague.
