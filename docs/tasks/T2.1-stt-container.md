## Goal

`docker compose up stt` starts a Speaches speech-to-text server with a pinned image and an English Whisper model that downloads by itself on a cold start. Posting a synthetic audio fixture to it returns a transcript containing the fixture's key words.

## Files

Create or change only these. Anything else: ask first.

- `docker-compose.yml` (add the `stt` service and a named model-cache volume; `api` is not wired to it yet)
- `docker-compose.gpu.yml` (CUDA image + NVIDIA device reservation; untested)
- `scripts/generate-audio-fixtures.ps1` (creates the WAV files with `System.Speech.Synthesis`)
- `tests/fixtures/audio/*.wav` and `tests/fixtures/audio/README.md` (sentences and key words per file)
- `README.md` (STT section: start, model, GPU override, port 8000)
- `.env.example` (only if the STT needs a variable; likely none)
