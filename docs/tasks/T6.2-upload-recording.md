## Goal

Page 1 has an **Upload recording** button beside Record and Download recording. It sends an audio file from disk through the same transcription path as a live recording, and the text is appended to the transcript box.

## Files

Create or change only these. Anything else: ask first.

- `web/src/recording/recorderReducer.ts`, `useRecorder.ts` (+ their tests): an `upload` action and `uploadFile`
- `web/src/report/ReportPage.tsx` (+ test): the button, a hidden file input, one hint line
- `web/src/styles.css` (only if the hint needs it)

## Out of scope

- New formats (`.m4a`, `.flac`, `.aac`): the API accepts four types only (human decision). m4a can be a later task after a live STT check.
- Any API, Docker or STT change; drag and drop; several files at once; trimming or converting audio; the Claude prompt or evaluation.

## Decisions (human, 2026-11-11)

1. Formats: `.wav`, `.mp3`, `.webm`, `.ogg` only, up to 25 MB (the API limits).
2. The browser's reported MIME type is not trusted: the file extension decides the type sent (`audio/wav`, `audio/mpeg`, `audio/webm`, `audio/ogg`).
3. Duration check in the browser: longer than the 5-minute recording limit is refused before upload. If the browser cannot read the duration, the file is sent anyway and the server limits apply (size, 120 s STT timeout).
4. One short hint line on Page 1 says what to do and what is accepted (English, formats, limits). Nothing more.

## Acceptance criteria

- [x] **Upload recording** sits beside Record; it opens a file picker limited to the four extensions.
- [x] A valid file is sent as multipart with the type taken from the extension (`song.WAV` with browser type `audio/x-wav` is sent as `audio/wav`); the text is appended to the transcript like dictation; "Transcribing…" shows meanwhile.
- [x] An unsupported extension, a file over 25 MB, or a file longer than 5:00 is refused with a clear message and nothing is sent.
- [x] A file whose duration cannot be read is still sent.
- [x] Upload is disabled while recording, requesting the microphone, transcribing or generating; Record is disabled while an upload is transcribing.
- [x] After a failed transcription of an uploaded file, **Try again** re-sends it and **Download recording** saves it (same as a live recording). A refused file offers no Try again.
- [x] The same file can be chosen twice in a row.
- [x] The hint line is shown; README documents the feature, formats and limits.
- [x] `node scripts/check.mjs --all` passes; default `dotnet test` unchanged.
