Stack

  • .NET minimal API with feature folders, typed results, one error handler returning ProblemDetails
  • React, Vite, TypeScript, no router, state library or UI kit
  • One contract: C# records generate the JSON schema and the TypeScript types
  • Docker Compose runs the app and the speech-to-text container
  • Tests run offline by default: xUnit, Vitest, Playwright smoke test

Models

  • Speech to text: faster-whisper (medium.en) served by Speaches through an OpenAI-compatible endpoint, so it can be swapped by changing a URL
  • Ticket generation: claude-sonnet-5-5, medium effort, structured output
  • Evaluation: Sonnet 5.5 compared with claude-haiku-5-5 on a fixed set of scenarios, to see whether the cheaper model is enough

How it was built

  • One plan of record with numbered decisions; the agent may not change it without asking
  • One task per session, each with a file list, acceptance criteria and a log
  • Hooks enforce the rules: protected files, build and tests before each handover, current task loaded at start
  • A separate reviewer agent checks each diff; a human approves every commit
  • Frozen test scenarios so the prompt is never tuned against its own exam
